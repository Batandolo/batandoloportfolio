Things I've built while learning.

Academic project

UniMart

UniMart is a campus marketplace web application designed for students to buy and sell items within their school community. It aims to provide a convenient platform for browsing listings and communicating with other users.

Key features

  • User registration and authentication
  • Product listings with image uploads
  • Search, category filtering, and sorting
  • Messaging between users
  • User dashboard and listing management

My contribution

Worked on developing application features, managing listing data, implementing user interactions, and improving the website interface.

What I learned

I gained practical experience with Django, database operations, authentication, file uploads, and organising features within a web application.

  • Django
  • Python
  • Tailwind CSS
  • MySQL

Prototype completed

Honey, I'm Home

A first-person psychological horror game in which the player must complete tasks, solve puzzles, and search for a way out of a house while avoiding a dangerous stalker. The game uses PS1-inspired low-poly graphics to create an unsettling atmosphere, with an emphasis on environmental design and tension.

Key features

  • First-person exploration
  • Puzzle-solving and task-based gameplay
  • Stalker encounters and stealth elements
  • Retro-inspired 3D environments
  • Atmospheric sound and lighting

My contribution

Contributed to developing the game prototype, including its environment, gameplay elements, and horror atmosphere.

What I learned

This project helped me understand 3D level design, gameplay implementation, environmental storytelling, and how sound and lighting affect a player's experience.

  • Godot Engine
  • GDScript
  • 3D Level Design

Research project · in progress

AI-Powered IT Career Assessment System

This project explores an AI-powered system intended to help IT students identify potential career paths based on their interests, skills, and knowledge. It also aims to connect career assessment results with relevant job opportunities.

Planned features

  • Interactive IT career assessment
  • Personalised career recommendations
  • Evaluation of skills and areas for improvement
  • Career and job opportunity mapping
  • AI-assisted interpretation of assessment results

My contribution

Working on the project concept, research, requirements, and planning for a system that connects IT student assessments with potential career opportunities.

What I aim to learn

The project is an opportunity to explore AI integration, assessment design, data-driven recommendations, and the development of technology that supports career planning.

  • Artificial Intelligence
  • Requirements Analysis
  • Research
